Audit

A dental clinic website that counted every visit as a conversion

I reviewed the clinic's WordPress site using only Google Tag Assistant and Chrome DevTools. I found four problems:

Tag Manager was loaded twice by a header plugin, so tags could fire twice.
The noscript tag was in the wrong place.
page_view and first_visit were set as Key Events, so they imported into Google Ads as conversions.
A separate Google Ads conversion fired on every page load.

Why it matters: Google Ads could end up optimising for visits instead of patient enquiries, and the reports would overstate results.
